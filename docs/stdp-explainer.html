STDP, and why the simulator never learns

The attention-brainslop branch of biocompute-outlier-labs. In short: the timing of stimulation should change the connections between neurons. The simulator records the right timing but only changes connections when a reward arrives, and our experiment code has no way to send one.

1. STDP: order matters

Two neurons, pre (A) and post (B), with a connection A→B. Drag the slider to change when B fires relative to A.

+5 ms

This is the simulator's rule: stdp_tau_pre_ms = 20, stdp_ltd_ratio = 0.5. Weakening is half as strong as strengthening and falls off over the same ~20 ms window.

2. Training with where + when

The stimulation pattern carries both pieces: where is which electrodes we stimulate, and when is the timing between groups. Fire key group K, then value group V 5 ms later, many times. STDP strengthens K→V. Afterwards, stimulating K alone makes V fire. Nobody gives the neurons the answer; the timing alone trains them.

Weight K→V starts at 0, so a query does nothing.

3. The gap in the simulator code

Path through src/organoid_simulator/lif_data_source.py, from a spike to a changed weight:

What the STDP step does (about line 700, every 40 µs frame). It only writes to elig, a short-lived record of which neurons fired together:

if stdp:
    elig += np.outer(fired_now, x_pre)              # causal: pre before post → +
    elig -= ltd_ratio * np.outer(y_post, fired_now)  # acausal: post before pre → −

The only code that changes the weights (line 770):

def apply_reward(self, reward):
    self._W += self._plasticity_lr * reward * self._elig
    ...
    self._elig[...] = 0.0

The data source runs inside the SDK's simulator subprocess. Our experiment talks to it only through neurons.stim() and spike readouts, and the SDK has no "reward" call. So apply_reward is never called, elig fades away (τ = 200 ms), and W never changes.

4. The fix: plain STDP, no reward

Biological STDP doesn't wait for a reward; the timing alone changes the synapse. The new option stdp_unsupervised: true applies elig to W at the end of every read batch, the same as calling apply_reward(+1) continuously. Only our simulator changes; the SDK and the experiment's API stay the same. The original reward-gated rule remains the default.

cl.sim.set_simulator_data_source(
    "organoid_simulator.lif_data_source:make_lif_source",
    config={"stdp_unsupervised": True, "coupling_gain_mV": 0.0},
)

honest caveat This gives the simulator a learning rule it didn't run before. It's standard textbook STDP, but simulator results are still not evidence about real CL1 tissue.

5. Attention on the 8×8 grid

The layout the experiment uses. A query stimulates part of the key region; learned K→V connections carry that activity to the values. Each value fires in proportion to how much the query overlaps its key: Σi overlap(q, ki) · vi. That's attention without softmax, because the model has no inhibitory neurons.
